# Head of Security

The person who can turn suspicion into lockdown.

- Alignment: Security
- Faction: Venue Security
- Roles: Command
- Status: Elite
- Tools: CCTV access, radio, keycards

## Role Summary
The Head of Security coordinates patrols, tightens the response, and seals exits when the mission starts to unravel.

## Example Fixtures
- Use for escalation, lockdown, CCTV, and keycard-access tests.
- Good fixture when we need a venue boss who can turn a local mistake into a map-wide problem.
