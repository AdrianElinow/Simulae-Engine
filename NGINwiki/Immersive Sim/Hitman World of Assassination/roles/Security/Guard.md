# Guard

The first line of venue enforcement.

- Alignment: Security
- Faction: Venue Security
- Roles: Enforcement
- Status: Active
- Tools: Radio, flashlight, sidearm

## Role Summary
Guards patrol the map, question suspicious behavior, and turn small mistakes into active danger.

## Example Fixtures
- Use for patrol routes, trespass checks, escort logic, and alarm escalation.
- Good baseline fixture for disguise testing because guards are the first real obstacle.
