An [[SimulaeNode/Simulae Actor]] will have responses to prompting [[Social Event]]s which must be either generated or selected from a set of possible responses based on a number of factors including logical responses to a prompting event, the [[SimulaeNode/Simulae Actor]]s [[Personality]] or [[Politics]] and the actor's personal [[Memories]]


Charisma dictates their filter effectiveness






## Most-Likely Responses

While internally, each response will be evaluated for its merit as a valid response for a given [[SimulaeNode/Simulae Actor]]s reaction to a prompting [[Social Event]], a smaller set of "most-likely responses" can provide an optimization / shortcut to a possibly more costly calculation.
